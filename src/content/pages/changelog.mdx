## Version 2.5.0 – October 6, 2025

- Added **AI-powered task prioritization** to help users focus on the most important items.  
- New **dark mode theme options** with customizable accent colors.  
- Enhanced **cross-device sync** for notes and tasks.  
- Improved **AI summarization speed** and accuracy.  
- Bug fixes and performance improvements.

---

## Version 2.4.0 – August 15, 2025

- Introduced **team workspaces** with shared folders and task boards.  
- Added **role-based permissions** for enterprise users.  
- Enhanced **calendar integrations** (Google Calendar, Outlook).  
- Fixed minor UI bugs in task management views.

---

## Version 2.3.0 – June 10, 2025

- Added **templates** for meeting notes, project checklists, and daily planning.  
- Improved **search functionality** across notes and tasks.  
- AI now provides **customizable summary lengths**.  
- Various performance improvements and bug fixes.

---

## Version 2.2.0 – April 5, 2025

- Added **mobile app support** for iOS and Android.  
- Introduced **offline mode** for notes and tasks.  
- Enhanced **AI suggestions for task creation** from notes.  
- Minor UX and accessibility improvements.

---

## Version 2.1.0 – January 20, 2025

- Initial release of **AI Note & To-Do App**.  
- Core features: note-taking, task management, AI summarization, and cross-device sync.  
- Basic integrations with calendar and cloud storage.
